# Warmth of Tribe - Game Mechanics

## Core Game Systems

### Life Stage Progression
The game follows the player character through five distinct life stages, each with unique gameplay elements:

1. **Childhood (Ages 3-12)**
   - Focus on learning basic skills
   - Limited responsibility and consequences
   - Exploration and discovery
   - Building initial relationships

2. **Teenage Years (Ages 13-17)**
   - Coming-of-age challenges
   - Skill specialization begins
   - Deeper social dynamics
   - Increased responsibilities

3. **Young Adulthood (Ages 18-25)**
   - Full tribal participation
   - Pair bonding and mate selection
   - Specialized role development
   - Independence and decision-making

4. **Parenthood (Ages 26-45)**
   - Child-rearing responsibilities
   - Leadership opportunities
   - Teaching the next generation
   - Balancing personal and tribal needs

5. **Elder Years (Ages 46+)**
   - Wisdom and storytelling
   - Tribal council participation
   - Mentoring younger members
   - Legacy creation

### Time Progression
- **Passage-based Aging**: Certain key passages advance age by specific amounts
- **Choice-based Time Skips**: Player can choose to advance time in certain situations
- **Seasonal Cycles**: Game tracks seasons with different resources and challenges
- **Day/Night Cycle**: Simplified tracking of time of day for appropriate activities

### Basic Needs System

#### Need Types
- **Hunger**: Decreases over time, affected by activities
- **Thirst**: Decreases more rapidly than hunger
- **Fatigue**: Builds up during activities, reduced by rest
- **Health**: Affected by other needs, injuries, and illnesses

#### Need Effects
- **Mild Deprivation**: Warning messages, minor skill penalties
- **Moderate Deprivation**: Significant skill penalties, limited action choices
- **Severe Deprivation**: Health damage, forced rest, potential death
- **Fulfillment Bonuses**: Skill bonuses when needs are well-satisfied

#### Need Management
- **Food Sources**: Hunting, gathering, tribal sharing
- **Water Sources**: Rivers, springs, collected rainwater
- **Rest Options**: Sleep at different times and locations
- **Health Restoration**: Herbal remedies, rest, care from others

### Skill System

#### Skill Categories
- **Survival Skills**: Hunting, tracking, fishing, fire-making
- **Gathering Skills**: Plant identification, foraging, water finding
- **Crafting Skills**: Tool-making, hide working, basket weaving
- **Social Skills**: Storytelling, leadership, trading
- **Physical Skills**: Running, climbing, swimming, strength
- **Knowledge Skills**: Medicinal plants, weather prediction, navigation

#### Skill Progression
- **Experience-Based**: Skills improve through use
- **Teaching Bonus**: Learning from skilled NPCs provides faster improvement
- **Practice Quality**: Focused practice improves skills more than casual use
- **Childhood Limitations**: Maximum skill levels are capped during childhood
- **Specialization**: Diminishing returns for broadly developed skills vs. specialization

#### Skill Checks
- **Success Chance**: Based on skill level, relevant attributes, and difficulty
- **Partial Success**: Some challenges allow for partial results
- **Critical Success/Failure**: Rare exceptional outcomes
- **Skill Synergies**: Related skills provide bonuses to each other

### Relationship System

#### Relationship Metrics
- **Affection**: How much an NPC likes the player
- **Respect**: How much an NPC respects the player's abilities
- **Trust**: How reliable the NPC considers the player
- **Overall Relationship**: Combined score affecting interactions

#### Relationship Building
- **Shared Activities**: Working, playing, or hunting together
- **Gift Giving**: Providing valued items to NPCs
- **Helping**: Assisting with tasks or problems
- **Successful Interactions**: Making appropriate dialogue choices

#### Relationship Effects
- **Dialogue Options**: Different options based on relationship level
- **Teaching Willingness**: Higher relationships increase teaching quality
- **Resource Sharing**: Better relationships lead to more generous sharing
- **Crisis Support**: NPCs with strong relationships provide more help in crises

### Character Development System

#### Attributes
- **Strength**: Physical power and endurance
- **Dexterity**: Coordination and agility
- **Perception**: Awareness of surroundings
- **Intelligence**: Problem-solving and learning
- **Charisma**: Social influence and communication

#### Character Traits
- **Earned Traits**: Developed through consistent choices and actions
- **Event Traits**: Gained through specific life experiences
- **Tribal Role Traits**: Based on specialized functions within the tribe
- **Reputation Traits**: How the character is perceived by others

#### Development Mechanisms
- **Choice Consistency**: Making similar choices builds related traits
- **Challenge Response**: How challenges are faced affects development
- **Mentor Influence**: Close relationships with NPCs affect trait development
- **Life Events**: Significant events can instantly grant traits

## Gameplay Mechanics

### Choice System

#### Choice Types
- **Dialogue Choices**: Conversations with NPCs
- **Action Choices**: Physical activities and tasks
- **Approach Choices**: How to handle situations (cautious, bold, etc.)
- **Time Allocation Choices**: What activities to prioritize
- **Ethical Choices**: Decisions affecting tribal harmony and values

#### Choice Consequences
- **Immediate Effects**: Direct results of choices
- **Delayed Effects**: Long-term consequences revealed later
- **Relationship Changes**: How NPCs respond to choices
- **Skill Development**: Activities chosen affect skill growth
- **Trait Development**: Consistent choice patterns develop character traits

### Resource Management

#### Resource Types
- **Food**: Various types with different nutritional values
- **Materials**: Hide, sinew, wood, stone, bone, etc.
- **Tools**: Created items that enable or improve activities
- **Medicinal Items**: Plants and preparations for healing
- **Personal Items**: Decorative or meaningful possessions

#### Resource Acquisition
- **Hunting**: Provides meat, hide, bone, sinew
- **Gathering**: Provides plants, berries, materials
- **Crafting**: Combines materials into tools and items
- **Trading**: Exchanges with tribe members or other tribes
- **Gifts**: Received from NPCs based on relationships

#### Resource Storage
- **Personal Inventory**: Limited items carried by player
- **Family Storage**: Shared resources within family unit
- **Tribal Storage**: Communal resources for all tribe members
- **Seasonal Considerations**: Food preservation and winter storage

### Event System

#### Event Types
- **Scheduled Events**: Seasonal celebrations, coming-of-age rituals
- **Random Events**: Weather events, animal encounters, illnesses
- **Triggered Events**: Occur based on player actions or conditions
- **Crisis Events**: Major challenges requiring tribal response
- **Life Milestone Events**: Birth, death, pair bonding, etc.

#### Event Responses
- **Multiple Approaches**: Different ways to handle each event
- **Skill-Based Outcomes**: Success chances based on relevant skills
- **Relationship Impacts**: How events affect tribal dynamics
- **Resource Effects**: Consumption or acquisition of resources
- **Character Development**: How events shape the player character

### Exploration System

#### Location Types
- **Home Camp**: Main tribal settlement
- **Hunting Grounds**: Areas with different animal populations
- **Gathering Areas**: Locations with specific plant resources
- **Water Sources**: Rivers, lakes, springs

#### Exploration Mechanics
- **Discovery**: Finding new locations and resources

### Tribal Dynamics

#### Tribal Roles
- **Leaders**: Decision makers and coordinators
- **Hunters**: Food providers and territory defenders
- **Gatherers**: Resource collectors and processors
- **Crafters**: Tool and item makers
- **Healers**: Health maintenance and restoration
- **Knowledge Keepers**: Tradition and information preservers

- **Group Hunts**: Coordinated hunting of large game
- **Celebrations**: Seasonal and achievement-based gatherings
- **Councils**: Decision-making for important matters
- **Trading**: Internal resource distribution and external exchange
- **Collective Labor**: Group projects like shelter building

#### Tribal Harmony
- **Contribution Tracking**: How much the player gives to the tribe

- **Value Alignment**: How player actions match tribal values

### Game Functions

#### Need Management
```javascript
// Update needs based on time passage and activities
window.gameUtils.updateNeeds = function(activity, duration) {
    // Different activities affect needs differently
    let hungerChange = 5 * duration; // Base rate
    let thirstChange = 7 * duration; // Base rate
    let fatigueChange = 3 * duration; // Base rate
    
    // Modify based on activity
    switch(activity) {
        case "running":
            hungerChange *= 1.5;
            thirstChange *= 2;
            fatigueChange *= 2;
            break;
        case "swimming":
            hungerChange *= 1.7;
            thirstChange *= 1.5;
            fatigueChange *= 2.2;
            break;
        case "resting":
            hungerChange *= 0.5;
            thirstChange *= 0.7;
            fatigueChange = -10 * duration; // Recover fatigue
            break;
        // Additional activities
    }
    
    // Apply changes
    State.variables.needs.hunger = Math.max(0, State.variables.needs.hunger - hungerChange);
    State.variables.needs.thirst = Math.max(0, State.variables.needs.thirst - thirstChange);
    State.variables.needs.fatigue = Math.min(100, Math.max(0, State.variables.needs.fatigue + fatigueChange));
    
    // Check for critical needs
    this.checkCriticalNeeds();
};

// Check if any needs are at critical levels
window.gameUtils.checkCriticalNeeds = function() {
    if (State.variables.needs.hunger <= 0) {
        State.variables.needs.health -= 5;
        return "hunger";
    }
    if (State.variables.needs.thirst <= 0) {
        State.variables.needs.health -= 10;
        return "thirst";
    }
    if (State.variables.needs.fatigue >= 100) {
        State.variables.needs.health -= 3;
        return "fatigue";
    }
    if (State.variables.needs.health <= 0) {
        // Handle death or extreme illness
        return "health";
    }
    return null;
};
```

#### Skill System
```javascript
// Perform a skill check
window.gameUtils.skillCheck = function(skill, difficulty) {
    // Base chance from skill level (0-100%)
    let skillLevel = State.variables.skills[skill] || 0;
    let chance = skillLevel * 10;
    
    // Modify by relevant attribute
    let relevantAttribute = this.getRelevantAttribute(skill);
    let attributeValue = State.variables.character.attributes[relevantAttribute];
    chance += attributeValue * 5;
    
    // Adjust for difficulty (0: very easy, 10: nearly impossible)
    chance -= difficulty * 10;
    
    // Adjust for needs
    if (State.variables.needs.hunger < 30) chance -= 10;
    if (State.variables.needs.thirst < 20) chance -= 15;
    if (State.variables.needs.fatigue > 70) chance -= 20;
    if (State.variables.needs.health < 50) chance -= 15;
    
    // Bound between 5% and 95% (always a small chance of success/failure)
    chance = Math.min(95, Math.max(5, chance));
    
    // Determine result
    let roll = Math.random() * 100;
    let success = roll < chance;
    
    // Critical success/failure
    let critical = false;
    if (roll < 5) {
        success = true;
        critical = true;
    } else if (roll > 95) {
        success = false;
        critical = true;
    }
    
    // Improve skill slightly on attempt, more on success
    this.improveSkill(skill, success ? 0.2 : 0.1);
    
    return {
        skill: skill,
        difficulty: difficulty,
        chance: chance,
        roll: roll,
        success: success,
        critical: critical
    };
};

// Improve a skill
window.gameUtils.improveSkill = function(skill, amount) {
    if (!State.variables.skills[skill]) return;
    
    // Apply learning rate modifiers
    if (State.variables.character.lifeStage === "childhood") {
        amount *= 1.5; // Children learn faster
    }
    
    // Apply specialization bonuses
    if (State.variables.character.specialization === this.getSkillCategory(skill)) {
        amount *= 1.3; // Bonus for focusing on specialization
    }
    
    // Apply diminishing returns for higher skill levels
    let currentLevel = State.variables.skills[skill];
    let diminishingFactor = 1 - (currentLevel / 15); // Slower improvement at higher levels
    amount *= Math.max(0.3, diminishingFactor);
    
    // Apply the improvement
    State.variables.skills[skill] += amount;
    
    // Cap based on life stage
    let cap = 10;
    if (State.variables.character.lifeStage === "childhood") cap = 5;
    else if (State.variables.character.lifeStage === "teenage") cap = 7;
    
    State.variables.skills[skill] = Math.min(cap, State.variables.skills[skill]);
};
```

#### Relationship System
```javascript
// Change relationship with an NPC
window.gameUtils.changeRelationship = function(npc, amount, type) {
    if (!State.variables.relationships[npc]) return;
    
    // Apply relationship change
    State.variables.relationships[npc] += amount;
    
    // Keep within bounds
    State.variables.relationships[npc] = Math.min(100, Math.max(0, State.variables.relationships[npc]));
    
    // Record significant changes
    if (Math.abs(amount) >= 5) {
        if (!State.variables.relationshipHistory) {
            State.variables.relationshipHistory = {};
        }
        if (!State.variables.relationshipHistory[npc]) {
            State.variables.relationshipHistory[npc] = [];
        }
        
        State.variables.relationshipHistory[npc].push({
            age: State.variables.character.age,
            change: amount,
            type: type || "general",
            value: State.variables.relationships[npc]
        });
    }
    
    return State.variables.relationships[npc];
};

// Get relationship tier description
window.gameUtils.getRelationshipTier = function(npc) {
    let value = State.variables.relationships[npc];
    
    if (value >= 90) return "devoted";
    if (value >= 75) return "close";
    if (value >= 60) return "friendly";
    if (value >= 45) return "neutral";
    if (value >= 30) return "distant";
    if (value >= 15) return "cold";
    return "hostile";
};
```

#### Time and Aging System
```javascript
// Age the character by a specified amount
window.gameUtils.ageCharacter = function(years, months) {
    years = years || 0;
    months = months || 0;
    
    // Convert to total months for precision
    let totalMonths = (years * 12) + months;
    
    // Current age in months
    let currentAgeMonths = Math.floor(State.variables.character.age * 12);
    
    // New age in months
    let newAgeMonths = currentAgeMonths + totalMonths;
    
    // Convert back to years with decimal
    State.variables.character.age = newAgeMonths / 12;
    
    // Check for life stage transitions
    this.checkLifeStageTransition();
    
    // Record aging point
    if (!State.variables.gameProgress.ageProgressionPoints) {
        State.variables.gameProgress.ageProgressionPoints = [];
    }
    
    State.variables.gameProgress.ageProgressionPoints.push({
        newAge: State.variables.character.age,
        passage: State.passage
    });
    
    return State.variables.character.age;
};

// Check if character should transition to a new life stage
window.gameUtils.checkLifeStageTransition = function() {
    let age = State.variables.character.age;
    let currentStage = State.variables.character.lifeStage;
    let newStage = currentStage;
    
    if (age >= 46 && currentStage !== "elder") {
        newStage = "elder";
    } else if (age >= 26 && currentStage !== "parent" && currentStage !== "elder") {
        newStage = "parent";
    } else if (age >= 18 && currentStage !== "youngadult" && currentStage !== "parent" && currentStage !== "elder") {
        newStage = "youngadult";
    } else if (age >= 13 && currentStage !== "teenage" && currentStage !== "youngadult" && currentStage !== "parent" && currentStage !== "elder") {
        newStage = "teenage";
    }
    
    // If stage changed, record the transition
    if (newStage !== currentStage) {
        State.variables.character.lifeStage = newStage;
        
        if (!State.variables.gameProgress.lifeTransitions) {
            State.variables.gameProgress.lifeTransitions = [];
        }
        
        State.variables.gameProgress.lifeTransitions.push({
            from: currentStage,
            to: newStage,
            age: age,
            passage: State.passage
        });
        
        return true;
    }
    
    return false;
};
```
